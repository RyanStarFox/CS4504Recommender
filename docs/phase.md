# 怎么并行

依赖只有三条:D的SASRec要接A的序列，B的融合要接D的SASRec，C的重排要接D的候选。
Agent等重排模型，由D最后接上。其余从第一天同时做。

## 第1天(同时)
- A
    - 写 split.py,交出 data/sequences.json 和 metrics.py
    - 另写一份 data/mock_candidates.json(流行度 Top-10)，格式与正式候选相同
- B
    - 写 device.py，先验证两模型小批量前向，再抽电影特征；用户属性文本默认关闭，作为独立可选消融
- D
    - 用A的序列写SASRec;序列未到之前，先把sasrec.py 的接口和训练循环写好
- C
    - 用mock 候选把SFT、DPO、GRPO的训练循环跑通

## 第2段(同时)
- A
    - 跑完第1–3行
- D
    - 训 SASRec, 把 data/candidates.json 换成正式 Top-10
- B
    - 用随机向量验证 fusion.py 的形状、梯度与模块开关；与D接入真实电影特征，跑5a/5b（均不含用户文本）；再准备第6行对齐
- C
    - 正式候选一到，只换输入文件，重跑第7-9行

## 最后
- D 写 agent_demo.py,调用已有的 genre filter、SASRec 和C的llama.cpp 重排。只演示，不进主表
- B、C、D 各交自己那几页幻灯片和讲稿要点
- A 收成一份report.pptx，并负责pre
