# 电影文本表示与对比对齐：讲稿

## 电影文本表示与门控融合

这里我们在电影ID向量之外增加了标题和类型。先用预训练语言模型抽取文本向量，再投影到64维，通过门控与ID向量相加。语言模型不参与训练，推荐模型和门控参数由交互数据学习。SASRec用这组表示编码历史，并给候选电影评分。

两种文本模型使用相同的数据划分和训练设置。GPT-2的NDCG略高，Qwen的命中率略高，整体接近，都没有超过表中的纯ID结果。纯ID原始训练配置没有保存，所以这里先保留结果对照，不能把差距完全归因于文本。测试覆盖全部6040位用户，按时间留出真实下一次交互。

## 电影行为表示与文本表示的对齐

接着固定Qwen编码器，只增加电影级对齐。我们把同一电影的ID向量和投影后的文本向量配成正例，其他电影作为负例。排序损失仍然是BPR，对齐损失是双向InfoNCE，权重0.01、温度0.07在运行前固定。

两个版本都从相同初始化开始，采用相同负采样、批次和早停设置。按验证集NDCG选出最佳参数后，增加对齐的模型在6040位测试用户中净增4位命中，NDCG绝对增加0.000616，相对约1.04%。变化不大，目前只跑了一个种子，因此我们把它看作一次小幅改善，还需重复实验确认。

## 工作小结

我负责文本表示这一部分：从电影元数据抽取冻结特征，把投影和门控接入推荐模型，再完成对齐实验。实验配置和训练记录都已保存。当前结果里，加入文本没有超过已有纯ID模型。接下来应先补齐同配置基线和重复实验，确认这种差异来自方法本身还是训练设置。
